# Hypernova Visual v5

Original deterministic noir-style vector emblem cards for all 30 roles, five public match banners and an eight-frame looping GIF brand intro. These are stylized symbols, not photographic/AI character portraits. 36 total assets; generated locally at build with Node standard library; no external links, dependencies, image service or user data. PNG 512x320, GIF 256x144. All textual game prompts remain unchanged; role artwork is requested via a private button in the catalog or private role message. Game start/end banner is decorative and queued after essential text. Media failures are swallowed, 2.5-second upload timeout, no retries, 5-second per-user gallery limit within an isolate plus existing ingress protection. /intro is private. Role artwork is public catalog content but actual role assignment never sent to group. VISUAL_MEDIA=false rollback switch via repository variable (redeploy); no DB migration.

Build commands: npm run visuals:generate, npm test, npm run typecheck, npm run cf:e2e. Generated TS is ignored by git and rebuilt by pre-scripts and Wrangler custom build. Unit tests check distinct role PNGs, GIF headers, private scope, media failure and multipart upload; real-runtime E2E checks multipart via fake Telegram. Actual Telegram rendering and client animation playback still need real-device verification. No claims of hand-painted character portraits or proven production throughput. No Mini App, changes to economy or mechanics.

Follow-up: unit validation now inflates every role PNG and parses eight GIF frames and pixel-code counts, and visual decoding is also inside the nonfatal guard.

E2E follow-up: separate original JSON transport from multipart; local proxy keeps v4 fetch behavior, real provider rejects redirects. The E2E fake provider parses multipart using native FormData and verifies the actual file bytes. Early outbound probe identifies a shared transport failure before cascading assertions. Previous E2E failure showed no ordinary messages; redirect compatibility is a suspected cause, not yet verified.
