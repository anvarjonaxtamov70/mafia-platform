# Hypernova Hero v6

Ten original collectible identities, two per rarity (Common, Rare, Epic, Legendary, Mythic). One starter free, others unlock automatically with earned collection XP thresholds 100–15,000. Levels 1–100 per hero (5 × (level − 1)^2), 25 XP for eligible completion / 50 XP for a win or personal win, 300 daily cap (UTC+5), max 49,005 per hero. Hero XP separate from ordinary account XP and Coins. No purchase, trading, paid boosts, XCoin, knife or Mini App; current role emblems reused for optional previews. All ten available for configured owners; no free earned XP or leaderboard boost. Revoked owner access falls back to starter if locked.

Only completed ranked games with at least 4 distinct real players; active means no missed eligible night/day actions under current v4 accounting. No AFK, left, fake/practice, unranked or banned/deleted-user awards. Selection freezes on claim in atomic registry transaction; cannot switch during active lobby/game. Old games lacking a snapshot use starter. Release/cancel cleans snapshots. Result and award writes are in the same SQLite transaction with per-game/player dedupe; no historical XP backfill. Daily cap reduces farming, not proof against collusion. No changes to engine, role probabilities, VIP, Stars, wallet or RP mechanics. No stats modifying gameplay.

Private commands /hero, /heroes, /herotop and main/profile menu; selection revalidated on server, group callbacks rejected by existing private-menu guard. TOP 10 sorted by earned collection XP; deleted and currently banned users excluded. Only public display names and earned XP shown. Existing anonymization retains ID-linked stats as before.

Additive tables only, no destructive migration. Current production Cloudflare implementation; VPS parity not included. Tests for unlock, level, XP cap, replay, owner access, selection snapshot, group forgery, cancellation, privacy, ineligible matches, real RoomCore result and workerd E2E menu checks. CI and live Telegram verification required before merge. Future: hero-specific cinematic art, optional separate battle mode, economy/marketplace only after design review and anti-abuse tests.
