# Command cleanup (Cloudflare)
Only handled group commands are cleaned up, with the exact original chat/message ID. Ordinary group messages, unrelated bot commands, private messages, callbacks and unsupported commands are not affected by this cleanup (existing night/dead moderation remains independent and may remove messages immediately). Direct replies are standalone and enqueue cleanup only after successful Telegram send. Lobby creation/reposts, join edits, start and cancel tie command IDs to their queued group responses; coalesced edits carry IDs forward. Failed or skipped responses do not trigger cleanup. Durable low-priority maintenance retries transient failures and drops permanent permission errors, without stopping game delivery. Existing Telegram delete permission required. At most 200 coalesced command IDs per response; extreme spam or responses superseded before delivery can leave a command visible. No change to Node/VPS runtime. Tests and fake-Telegram E2E added; real Telegram and final CI pending.
Follow-up: handled group commands are excluded from immediate night/dead deletion and use response-linked cleanup only. Unhandled commands and normal chat still follow moderation. Regression tests assert exact cancellation-response ordering, single deletion, night/dead status commands and failed response behavior.
