# Lobby v12 (Cloudflare production)
One active Registry claim per user. Destination join prevalidates game, capacity, DM and ban before trying a transfer. Source checks exact game number and refuses RUNNING/starting; removes waiting player via existing durable leave operation. Release is processed before destination retries its original numbered game. Registry unique claim remains final arbiter across simultaneous attempts. No running /leave escape; lock remains until finish/cancel. A failed destination retry (e.g. fills or starts during transfer) may leave the player out of both lobbies; cannot guarantee an atomic move across DOs. Registry outage fails closed; retry after durable release. No changes to ranked rewards.
Repeated /game or /quick in existing lobby reissues same number, mode, players and deadline, without autojoining caller. Pending sends coalesce and delivered reposts have a 2s group interval; old board keyboard is cleared and exact message unpinned, latest board pinned. Old callback for same game remains server-validated. Closing or cancelling lobby retires current board; no unrelated pins touched. Pin/clear/unpin queue is persisted and separate from critical messages, retries transient errors up to five attempts, respects 429 delay and drops permanent 400/403 errors. Bot must have pin permission. Telegram send itself is at-least-once; crash after send before persistence may leave an orphan message. No live Telegram confirmation yet. Existing Node/VPS alternate runtime not updated. CI required.

Manual-start revision: /startgame replaces /gstart. All registration timers disabled (including existing saved flags and alarms); no timeout cancellation. Only verified admins and configured superadmins can start, legacy start callbacks rejected, internal auto trigger denied. Settings no longer exposes registration timers; running phase alarms unchanged. Persistent registration requires explicit admin start/cancel or member exit/transfer. Node service and Telegram adapter manual-start policy updated; other v12 lobby features still Cloudflare only.
